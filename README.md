실시간 협업 무한 캔버스 툴 — 브라우저만 있으면 바로 시작, 링크 공유로 팀과 함께 그립니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 무한 캔버스 | 마우스 휠·핀치 줌, 패닝으로 끝없이 펼쳐지는 작업 공간 |
| 펜 & 지우개 | 펜 3가지 굵기·5가지 색상 / 3가지 크기 소프트 브러시 지우개 |
| 포스트잇 | 5가지 색상, 이동·리사이즈·텍스트 편집, 글자 크기 4단계, 가장자리 핸들로 화살표 연결, 자석 스냅 |
| 도형 | 사각형, 원, 삼각형, 화살표(3가지 굵기) |
| 이미지 삽입 | Ctrl+V 붙여넣기 또는 드래그 & 드롭으로 이미지 추가·이동·리사이즈, 우클릭으로 앞뒤 순서 조절 |
| 배경 제거 | 이미지 위 가위 버튼 또는 꾹 누르기로 실행. 인물 사진은 AI로, 로고·텍스트 같은 그래픽은 명도 분석으로(흰/검은 배경 자동 판별) 처리, Ctrl+Z로 원본 복구 |
| 선택 툴 | 드래그로 여러 항목 범위 선택 후 한 번에 이동, Backspace/Delete로 일괄 삭제, 선택 박스 모서리로 한꺼번에 크기 조절(비율 유지) |
| 그룹 | 여러 항목을 선택해 그룹으로 묶으면 하나만 클릭해도 전체가 함께 선택·이동 (그룹 해제 가능) |
| 협업 To-Do | 툴바 캘린더에서 날짜를 골라 할 일 작성·체크·삭제, 팀원과 실시간 동기화 |
| 실시간 협업 | Pusher 기반 커서·획·포스트잇 실시간 동기화, 현재 접속자 표시 |
| 팀 초대 & 비공개 방 | 공유 버튼 → 초대 링크 복사(7일 유효), 비공개로 전환하면 초대된 멤버만 입장, 멤버 목록·내보내기 |
| Google 로그인 / 게스트 입장 | Google 계정으로 즉시 입장, 로그아웃 시 계정 초기화 / 로그인 없이 게스트로 체험 (게스트가 만든 방은 마지막 편집 24시간 후 자동 삭제) |
| 프로젝트 사이드바 | 좌측 사이드바에서 프로젝트 전환·추가·삭제 (`×` 버튼 + 확인 창), 우클릭으로 이름 변경 |
| 휴지통 | 삭제한 프로젝트 목록을 이 브라우저에 보관(최대 20개), 클릭으로 내용 열람, `×`로 목록·로컬 사본 삭제 (서버의 방 데이터는 남음) |
| 자유 이동 패널 | 상단 툴바·좌측 사이드바를 드래그로 자유롭게 이동 (PC), 위치 자동 저장 |
| 모바일 최적화 | 터치 드로잉·핀치 줌·이미지 터치 이동/리사이즈, 기종별 safe-area 대응 |
| 데이터 보존 | 방 상태는 서버(Vercel KV)에 저장, 브라우저(localStorage)에도 사본을 남겨 서버가 비어 있을 때 복원 |
| 한/영 전환 | UI 언어를 한국어·영어로 전환 |

> AI 이미지 변환(이미지 더블클릭 → 프롬프트로 스타일 변환)은 UI에 남아 있지만, Hugging Face 무료 프로바이더(hf-inference)가 GPU 이미지 생성을 더 이상 지원하지 않아 현재 동작하지 않습니다.

## 기술 스택

| 분류 | 기술 |
|------|------|
| 배포 | Vercel (Serverless Functions) |
| 실시간 | Pusher Channels (Presence Channel + Client Events) |
| 저장소 | Vercel KV (Redis) + localStorage 사본 |
| 인증 | Google Identity Services (GIS) OAuth 팝업 |
| 프론트엔드 | Vanilla JS, Canvas API |
| 백엔드 | Node.js Serverless (`/api/*.js`) |
| AI 이미지 처리 | Hugging Face, 별도 Express 서버(`hf-server/`, Render 배포) |

## 로컬 개발

### 1. 설치

```bash
npm install
```

### 2. 환경변수 설정

`.env` 파일 생성:

```env
PUSHER_APP_ID=your_app_id
PUSHER_KEY=your_key
PUSHER_SECRET=your_secret
PUSHER_CLUSTER=your_cluster

# 선택 — 없으면 방 상태가 서버에 저장되지 않고(브라우저 사본만 남음),
# 팀원 관리·방 이름 변경은 동작하지 않음
KV_REST_API_URL=your_kv_url
KV_REST_API_TOKEN=your_kv_token

# /admin.html 통계 페이지 접근 키
ADMIN_STATS_KEY=추측하기_어려운_긴_무작위_문자열
```

### 3. 서버 실행

```bash
npx vercel dev  # /api/* 서버리스 함수까지 실행 (.env 사용)
```

`npm start` / `npm run dev`는 구버전 `server.js`(정적 파일 + WebSocket)만 띄우고
`/api/*`를 실행하지 않으므로, 페이지는 열리지만 방 입장·저장·실시간 동기화는 동작하지 않는다.

### 4. 테스트

```bash
npm test
```

`api/*.js`의 핵심 동작(획·노트·이미지·도형 삭제/이동, 지우개 결과, To-Do, 게스트 방
만료, 비공개 방 멤버 검증, 방 입장·조회, 프로젝트 이름 변경, 일괄 이동·그룹, 관리자
통계, 보안 회귀 — roomId 키 충돌·KV 실패·락·다른 앱 토큰 거부 등)을 실제 KV·Pusher·Hugging Face 없이 인메모리 가짜 구현으로 검증한다 (`tests/`,
Node 내장 테스트 러너 사용, 별도 설치 불필요 — `@vercel/kv`·`pusher`는 `npm install`로
이미 받는 의존성을 그대로 재사용). 소유권 정책처럼 한 번 조용히 깨졌던 적 있는 동작은
회귀 테스트로 고정해뒀다.

## Vercel 배포

### 환경변수

| 변수명 | 필수 | 설명 |
|--------|------|------|
| `PUSHER_APP_ID` | ✅ | Pusher 앱 ID |
| `PUSHER_KEY` | ✅ | Pusher 키 |
| `PUSHER_SECRET` | ✅ | Pusher 시크릿 |
| `PUSHER_CLUSTER` | ✅ | Pusher 클러스터 (예: `ap3`) |
| `ADMIN_STATS_KEY` | ✅ | `/admin.html` 통계·문의 조회 키 |
| `KV_REST_API_URL` | 선택 | Vercel KV URL (없으면 서버 저장·팀원 관리·이름 변경 불가) |
| `KV_REST_API_TOKEN` | 선택 | Vercel KV 토큰 |

### Pusher 설정

- Pusher 대시보드 **App Settings → Enable client events** 활성화 필수 (커서·그리는 중인 획 공유에 사용)

### Google OAuth 설정

Google 클라이언트 ID는 `app.html`의 `GOOGLE_CLIENT_ID`에 하드코딩돼 있고, 서버는 토큰이 이
클라이언트로 발급된 것인지 확인한다(`lib/auth.js`). 본인 OAuth 클라이언트를 쓰려면 `app.html`
값을 바꾸고 Vercel 환경변수 `GOOGLE_CLIENT_ID`에도 같은 값을 넣은 뒤, Google Cloud Console → 사용자 인증 정보 →
**Authorized JavaScript origins** 에 배포 URL 추가:

```
https://your-domain.vercel.app
```

### AI 서버 (배경 제거)

`hf-server/`를 Render에 배포하고(`render.yaml` 포함) 환경변수 `HF_TOKEN`(Hugging Face
토큰)을 설정한 뒤, `app.html`의 `HF_SERVER_BASE`를 배포 주소로 바꾼다. AI 서버는 허용된
출처(`ALLOWED_ORIGINS`, 기본값 `https://freedomai-app.vercel.app`과 localhost)에서 온 요청만
받고, IP당 분당 5회·서버 전체 분당 60회(`GLOBAL_RATE_LIMIT`)로 Hugging Face 호출을 제한한다.
다른 주소로 배포하면 `ALLOWED_ORIGINS`에 그 주소를 넣는다.

## 주요 정책

- 룸당 최대 획 1,000개 (획당 점 5,000개)
- 포스트잇 텍스트 최대 10,000자 / 너비 100~3,000px, 높이 80~3,000px / 글자 크기 10~32px
- 이미지: 룸당 최대 20개, 붙여넣기·드롭 시 최대 1,200px로 자동 압축 (JPEG 82%, 투명 배경은 흰색으로)
- 도형: 룸당 최대 300개
- To-Do: 날짜당 최대 50개, 항목당 200자
- 프로젝트 이름 최대 32자
- 지우개: 클라이언트에서 직접 계산 후 결과 전송 (KV 없이도 동작)
- 삭제·이동(포스트잇/이미지/도형/획): 방에 입장할 수 있는 사람이면 작성자 구분 없이 가능 (지우개와 동일 정책). 실행 취소는 내 획만 가능
- 게스트가 만든 방: 마지막 편집 24시간 후 자동 삭제
- 데이터: 방 상태는 Vercel KV에 저장, 브라우저 localStorage에도 사본 저장 (서버가 비어 있을 때 복원)
- 패널 위치(툴바·사이드바): PC에서 드래그 이동, localStorage에 저장

### 2026-10-01
- **로그인 만료 처리** — Google 로그인 토큰(약 1시간 유효)을 갱신하지 않아, 1시간이 지나면 비공개 방의 모든 저장이 조용히 실패하고 사이드바로 이동하면 멤버인데도 "비공개 프로젝트" 안내가 떴음. 이제 만료 5분 전(또는 서버가 인증 실패로 거절하면) 툴바 아래에 "로그인 연장" 배너가 뜨고, 클릭 한 번으로 계정 선택 없이 새 토큰을 받은 뒤 서버 상태로 다시 맞춤. 사이드바 이동 시에도 토큰이 곧 만료되면 로그인을 건너뛰지 않음. 실시간 연결 인증도 매번 최신 토큰을 쓰도록 변경

- **보안: 방 이름 키 충돌 차단** — 방 이름을 `"다른방:members"`처럼 보내면 그 방의 멤버 이메일을 읽거나, 멤버 목록을 덮어써 아무도 못 들어오게 잠그거나, 이름 변경으로 옮겨 비공개를 풀 수 있었음. 모든 API에서 `:members`·`:lock`으로 끝나는 방 이름을 거부하고, 깨진 멤버 목록이 있어도 500으로 죽지 않게 함
